# Система рекомендаций постов

Проект представляет собой рекомендательную систему для социальной сети, которая предсказывает вероятность взаимодействия пользователя с постом и возвращает персонализированные рекомендации.

## Стек технологий

* Python
* CatBoost
* FastAPI
* PostgreSQL
* Pandas

## Основные возможности

* обучение модели CatBoostRegressor;
* генерация признаков пользователей и постов;
* учет текстовых и временных признаков;
* REST API для получения рекомендаций.

## Результаты

* **Модель:** CatBoostRegressor
* **Обработка текста:** CatBoost Text Features
* **Метрика качества:** HitRate
* **Лучший результат:** **HitRate = 0.55+**
